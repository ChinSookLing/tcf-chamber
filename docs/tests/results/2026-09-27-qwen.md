## Causes (checked by Opus)

1. **Stale cache.** Qwen quoted the pre-5c index ("078. 文明呼吸的流動 · Copilot", "001. 雨中之印"). GitHub Pages sends `cache-control: max-age=600`; the test began about 2 minutes after the deploy. Not a site fault, but it shows why the 5c fix mattered: the old row numbers misled Qwen exactly as Kimi warned.
2. **Link-blind fetch tool (site can help).** Qwen's tool returned page text without link targets. The home page's plain text had labels ("Start Here · For AI readers · License") but no URLs, so Qwen guessed paths (`/ch078`, `/chambers/078`, `/text/078`, `/index.json`) and got 404s. Fix: Phase 5d adds full URLs as visible text.

## Good behaviour

- Did not invent content for pages it could not open.
- Listed every failed URL.

## Run 2 (same conversation, after run 1 failed; site still at Phase 5c)

- **What Qwen did:** it could not open the chamber pages, so it went outside the given scope and read the raw editing data on GitHub (`raw.githubusercontent.com/.../docs/data/chambers.json`) and the repo page. It disclosed this openly: every answer names its GitHub source, and Q12 lists the GitHub URLs. The site itself does not link to GitHub; the repo address is easy to infer from the `github.io` URL, and the README then called `chambers.json` the "single source of truth".
- **Not counted as a scored run** (outside the test scope), but kept as a real-world observation: AI readers will look for other sources when blocked.

**Lesson:** the raw editing file lacks the evidence layer (roles and evidence, license, descriptions, review status), so an AI that reads it gets exactly the attribution, license and description questions wrong. Fix (Phase 5d): a "For AI readers" signpost at the top of `README.md` and `docs/data/README.md`, pointing to the published records.

**Test protocol change:** put "Use only this website" as the first line of the prompt, not inside the rules list.

## Lesson for the Profile

- Wait at least 10 minutes after a deploy before an outsider test.
- Key addresses must appear as visible plain-text URLs, not only as link targets.
