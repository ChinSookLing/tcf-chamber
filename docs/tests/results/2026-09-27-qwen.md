## Causes (checked by Opus)

1. **Stale cache.** Qwen quoted the pre-5c index ("078. 文明呼吸的流動 · Copilot", "001. 雨中之印"). GitHub Pages sends `cache-control: max-age=600`; the test began about 2 minutes after the deploy. Not a site fault, but it shows why the 5c fix mattered: the old row numbers misled Qwen exactly as Kimi warned.
2. **Link-blind fetch tool (site can help).** Qwen's tool returned page text without link targets. The home page's plain text had labels ("Start Here · For AI readers · License") but no URLs, so Qwen guessed paths (`/ch078`, `/chambers/078`, `/text/078`, `/index.json`) and got 404s. Fix: Phase 5d adds full URLs as visible text.

## Good behaviour

- Did not invent content for pages it could not open.
- Listed every failed URL.

## Lesson for the Profile

- Wait at least 10 minutes after a deploy before an outsider test.
- Key addresses must appear as visible plain-text URLs, not only as link targets.
